# SDS 510 – Module 05 Basics  
Jeopardy! Question Classification (Naive Bayes)

This repository contains my work for the SDS 510 Module-05 Basics assignment.  
The goal of this module was to build a text classification pipeline to predict  
whether Jeopardy! questions are “high value” or “low value” using a  
Naive Bayes classifier.

### Contents
- **module-05-basics.ipynb** — main notebook with:
  - loading and cleaning the Jeopardy dataset  
  - tokenization using NLTK  
  - vectorization with CountVectorizer  
  - Naive Bayes model training  
  - accuracy score output
